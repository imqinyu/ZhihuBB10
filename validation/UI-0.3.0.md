# 0.3.0 登录导入、题图与个人主页

2026-10-25，原生 Cascades 1.4 / Qt 4.8；模拟器 192.168.106.129，BB10 10.3.1.995。

## 实现

- 导入支持 document.cookie 输出、外层单双引号、Cookie: 前缀；保留名称／值分隔，拒绝内部换行与超长输入。只在 /me 返回实际用户资料后保存，验证失败不覆盖既有账号。
- 登录页增加原生剪贴板“粘贴”action。账号当前行及已保存行可长按复制凭据／删除账号；原文只由 C++ 直接写入剪贴板，列表仍不含 Cookie 字段，不打印凭据。删除当前账号会退出当前登录，不影响其他保存账号。
- 问题页隐藏固定 TitleBar，把题图作为列表首项，使用用户提供的 question_background.png；回答条目不再重复显示问题名。题图点击无跳转，滚动会离开屏幕；首项不计入回答数、不写入回答缓存。
- 设置保存不再发 settings_saved toast；复制与收藏等其他操作提示保留。
- 新 UserDetailPage 参考 BBTiebaUI 的背景／头像／统计行／SegmentedControl 布局，提供提问、回答、文章。账号 Tab 显示本人主页，底部进入账号管理；回答条目长按“作者主页”和正文菜单也可打开他人主页。三个栏目独立分页与缓存，账号切换后重新按账号作用域加载。

## 实际限制

- 用户这次提供的 document.cookie 输出不含 z_c0，/me 实测 401；补齐之前的登录凭据后 /me 成功。document.cookie 无法读取 HttpOnly Cookie，所以不能承诺仅此输出即可完成登录。应用给出明确错误，并说明从 Network 复制完整 Cookie。
- 文章栏目已连接移动 API 与分页／缓存处理，但本次请求被知乎安全验证拦截（403，错误码 40362），未验证成功的文章列表。旧 members 路径在移动域返回 404，文章使用 people 路径；没有将错误响应伪装为空列表或成功。
- Q20 真机未连接，本轮只验证模拟器。
