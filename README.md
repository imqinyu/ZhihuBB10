# 知乎黑莓10原生版

## 说明

基于黑莓 Cascade 框架 遵循Blackberry10的界面设计准则

目前处于测试阶段，还有很多没有实现的功能和 bug

这是越狱软件，要安装请先将您的黑莓越狱

目前可以：

- 浏览问题和回答
- 打开用户资料页
- 浏览日报
- 查看评论区

仅供学习使用，禁止倒卖

欢迎加入 BlackberryPhonix QQ 交流群：892633534
